> 本文件供 **AI 编码助手**在协助制作「商汤小浣熊参赛作品」时阅读，确保作品发布时正确、安全地接入参赛标志（`参赛作品标志.js`），且**绝不因标志脚本异常而影响作品本体运行**。

## 一、标志文件说明

| 项目 | 内容 |
|---|---|
| 文件 | `参赛作品标志.js` |
| 作用 | 页面加载后在屏幕上方以"灵动岛"风格动画提示：这是商汤小浣熊参赛作品，作者为「软软的小窝」 |

## 二、集成原则（必须遵守）

### 核心原则：**Fail-Safe（故障隔离）**

> **`参赛作品标志.js` 是"装饰性增强"，不是作品功能的一部分。**
> 任何情况下（脚本缺失、加载失败、执行报错、超时阻塞），**作品主 HTML 必须正常渲染、交互正常、功能完整**。

### 强制要求

1. **不得阻塞主页面解析**
   - 使用 `async` 或 `defer` 加载，或把 `<script>` 放在 `<body>` 末尾。
   - 禁止把标志脚本放在 `<head>` 中且无 `async/defer` 的同步加载方式（避免阻塞首屏）。

2. **不得依赖标志脚本的执行结果**
   - 作品代码**禁止**读取/调用标志脚本暴露的任何变量、函数或 DOM 节点。
   - 标志脚本与作品逻辑**零耦合**。

3. **加载失败不影响主页面**
   - 通过 `onerror` 捕获加载失败并静默忽略（仅 `console.warn`，不打断后续执行）。
   - 标志脚本自身已用 `try/catch` 包裹初始化，单个 `throw` 不会污染全局。

4. **路径可靠**
   - `参赛作品标志.js` 必须与主 HTML **同目录**，或使用经确认的绝对/相对路径。
   - 发布前验证文件确实存在且可访问（HTTP 200）。

## 三、推荐引入方式（AI 应优先采用）

### ✅ 方式 A：`<body>` 末尾 + `async`（推荐）

```html
<!-- 在HTML文件中引入外部JavaScript文件 -->
<script src="参赛作品标志.js" async></script>
```

放置位置：紧邻 `</body>` 之前。优点：不阻塞解析，标志动画在页面就绪后自然触发。

### ✅ 方式 B：`<head>` 中 + `async`（也可接受）

```html
<head>
  ...
  <script src="参赛作品标志.js" async></script>
</head>
```

### ⚠️ 方式 C：带失败兜底（如宿主环境对脚本加载失败敏感）

```html
<script>
  // 标志脚本失败兜底：不影响主页面
  window.__flagLoaded = false;
</script>
<script src="参赛作品标志.js" async onerror="window.__flagLoaded=false;console.warn('参赛标志加载失败，已忽略')"></script>
```

> AI 在生成/修改作品代码时，**默认采用方式 A**；仅当上下文明确提到"需要加载失败监控"时才采用方式 C。

## 四、禁止事项（AI 不得执行）

| 禁止 | 原因 |
|---|---|
| ❌ 在标志脚本加载前就调用其函数 / 读取其变量 | 脚本可能未加载，导致主页面报错 |
| ❌ 把作品关键逻辑写进标志脚本 | 标志脚本是可缺失的增强层，非必需依赖 |
| ❌ 用同步 `<script>`（无 async/defer）放在 `<head>` 顶部 | 可能阻塞首屏，违背 fail-safe |
| ❌ 因标志脚本报错而在主页面抛出未捕获异常 | 必须隔离，装饰层故障不影响主体 |
| ❌ 修改作品既有 DOM / 样式以"适配"标志 | 标志脚本自包含样式，作品无需改动 |

## 五、发布前自检清单（AI 协助验证）

- [ ] `参赛作品标志.js` 与主 HTML 同目录（或路径正确可访问）
- [ ] 引入标签使用了 `async` 或位于 `<body>` 末尾
- [ ] 浏览器打开作品：标志动画正常出现并自动消失
- [ ] **模拟标志脚本 404（临时改名）**：作品页面仍正常渲染、功能完整、控制台仅有 warn
- [ ] 作品代码中无任何对标志脚本 API 的直接依赖
- [ ] 移动端（≤380px）下标志胶囊显示正常、不溢出

## 六、协作提示（给 AI）

- 当用户提供作品代码并说"把参赛标志加进去"时：**仅添加上述 `<script>` 引入标签，不修改作品任何既有内容**。
- 当用户要求"确保标志不影响主页面"时：按本文件**第三节方式 A** 接入，并可附加**方式 C** 的 `onerror` 兜底。
- 若用户后续调整标志文案/时长/配色，应修改 `参赛作品标志.js` 本身，**不应改动作品 HTML 结构**。
